# 智能家居控制系统

这是一个基于 STM32F103 的智能家居项目，主要用于实现温湿度采集、WiFi 连接、MQTT 数据上云以及基础设备控制。项目结合了 ESP8266 模块、OneNET 云平台、DHT11 传感器和 OLED/LED 等外围设备，适合用于学习嵌入式、网络通信和云端接入。

## 1. 项目概览

本项目以 STM32F103 为核心控制芯片，完成以下功能：

- 温湿度采集：DHT11 传感器读取环境温湿度
- WiFi 通信：ESP8266 作为网络模块进行连接
- MQTT 通信：通过 MQTT 协议与云平台交互
- 云平台接入：接入 OneNET 平台进行数据上报与控制
- 设备状态指示：LED 灯状态提示
- 按键处理：用于交互或控制触发
- 屏幕显示：OLED 显示相关状态信息

## 2. 硬件平台

- MCU：STM32F103
- WiFi 模块：ESP8266
- 传感器：DHT11
- 显示：OLED 0.96寸
- 控制器件：LED、按键、蜂鸣器等
- 通信：UART、I2C 等

## 3. 主要功能

### 3.1 温湿度监测

- 使用 `DHT11_Read_Data` 读取环境数据
- 温度和湿度通过串口输出，并上传到云端

### 3.2 ESP8266 网络连接

- 通过串口与 ESP8266 通信
- 完成 WiFi 连接、TCP 连接、MQTT 建链等流程
- 代码中包含常见的 AT 指令处理逻辑

### 3.3 MQTT + OneNET

- 使用 MQTT 协议与 OneNET 平台通信
- 支持设备连接、订阅主题、消息发布和消息处理
- 适合扩展用于远程监控或家庭设备控制

### 3.4 设备状态反馈

- LED 用于状态指示
- 按键可用于本地控制或模式切换
- OLED 可用于显示实时参数

## 5. 配置说明

在实际使用前，需要检查以下内容（需要根据实际情况修改个性化参数，如wifi密码）：

- ESP8266 的 WiFi SSID 和密码
- OneNET 设备接入参数
- MQTT 服务器地址与端口
- 串口波特率设置
- DHT11 接线是否正确

代码中关键配置，例如：

- WiFi 连接 AT 命令
- OneNET 设备认证参数
- MQTT 连接目标地址

这些参数通常需要根据实际设备信息修改。
